# CRM André

Aplicação web responsiva para apoiar contatos, oportunidades, tarefas, atividades e pontuação na corretagem imobiliária.

## Estado atual
- Interface inicial publicada como site estático.
- Contatos com classificação A/B/C/D/E/F/O.
- Oportunidades, tarefas, retornos, atividades e pontos manuais.
- Layout adaptável a computador e celular.

## Limitação importante
Esta versão inicial guarda os dados no armazenamento local do navegador. **Não há sincronização entre dispositivos nem entre usuários. Não use dados reais/confidenciais de clientes ainda.** A próxima etapa é configurar autenticação, banco PostgreSQL/Supabase com Row Level Security, auditoria, backups e sincronização antes do uso operacional.

Não coloque credenciais, chaves privadas ou backups de clientes neste repositório.
